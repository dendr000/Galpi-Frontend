# 사용 방법

[← 문서 목록으로](./README.md)

## 실행하기

### 개발 환경 (웹)

1. `Galpi-Backend`를 MySQL과 함께 기동 (기본 프로파일, 포트 18080)
2. 이 저장소에서:
   ```bash
   npm install
   cp .env.example .env   # VITE_API_BASE_URL을 백엔드 주소로
   npm run dev              # http://localhost:9691
   ```

### 데스크톱 (Exe)

`Galpi-Exe/release/`의 실행 파일을 더블클릭하면 끝입니다. MySQL, Node, 별도 서버 실행이 전혀 필요 없는 완전 오프라인 단일 프로그램이며, 내부적으로 백엔드가 H2(내장 DB)로 자동 기동됩니다. 데이터는 `~/.galpi/`에 저장되어 프로그램을 다시 설치해도 유지됩니다. 자세한 배경은 [ARCHITECTURE.md](./ARCHITECTURE.md) 참고.

## 로그인

회원가입이 없는 개인용 노트 앱입니다. **패스프레이즈 하나**로만 여는 "시크릿 게이트" 화면이 뜨는데, 서재/성좌표/터미널/추적 4가지 연출 중 매번 무작위로 하나가 나타납니다. 올바른 문구를 입력하면 게이트가 열립니다.

## 작품(위키) 만들기

- 홈 화면에서 새 작품을 만들고, 분류(장르 태그)를 지정합니다.
- 분류에 특정 키워드(예: 무협 · 사이버펑크 · 아포칼립스 · 히어로 · 헌터 · 동양판타지 · 괴담 계열)가 들어가면, 그 장르 전용 테마(배경 · 폰트 · 커서 · 클릭 이펙트)가 자동으로 적용됩니다. 한 장르에 테마가 여러 종류 있으면 상단 내비게이션의 팔레트 버튼으로 순환하며 고를 수 있고, 자동 추천 대신 직접 하나를 고정할 수도 있습니다.
- 작품 상세 페이지 아래로 하위 문서(설정 · 등장인물 · 사전 등)를 자유롭게 만들어 트리 구조로 쌓아갈 수 있습니다.
- **웹툰**, **소설** 폴더 아래에 새 하위 폴더를 만들면 등장인물 · 사전 같은 보조 폴더와 시작 메모가 자동으로 함께 생성됩니다.

## 문서 작성

문서 본문은 마크다운을 기반으로 하되, 갈피 전용 확장 문법(스탯 차트, 관계도, 대화 로그, 백링크 등)을 함께 쓸 수 있습니다. 전체 문법은 [SYNTAX.md](./SYNTAX.md)에 정리했지만, 실제로는 에디터에 붙어있는 **매크로 툴바**(표 · 차트 · 게이지 · 타임라인 버튼)로 대부분 자동 삽입되기 때문에 문법을 외울 필요는 크지 않습니다.

## 캐릭터 관리

- 캐릭터 갤러리에서 카드 형태로 등장인물을 관리하고, 상세 화면에서는 이미지 · 핵심 속성 인포박스 · 마크다운 본문을 함께 볼 수 있습니다.
- **Bulk Studio**는 모든 등장인물의 속성을 엑셀처럼 한 화면(그리드)에서 일괄 조회 · 수정하는 별도 작업 공간입니다. 커스텀 속성 열을 자유롭게 추가할 수 있고, 찾아바꾸기도 지원합니다.

## 집필 보조 — 플로팅 메모 (FAB)

화면 우측 하단 플로팅 버튼에서 여러 보조 도구를 바로 불러올 수 있습니다.

- **메모** — 원고와 별개로 쓰는 폴더형 메모장. 서식 · 표 · 각주 · 책갈피를 지원하고 3초 자동 저장됩니다.
- **상용구** — 자주 쓰는 문구를 등록해두고 검색 후 바로 붙여넣는 도구. `...`처럼 짧은 트리거를 등록해두면 입력 중 자동으로 치환되도록 쓸 수도 있습니다. 상용구는 폴더로 나눠 정리할 수 있고, 관리 창에서 폴더를 고르면 그 폴더(와 '공통')의 상용구만 에디터에서 쓰입니다 — 정리를 마치고 창을 닫으면 자동으로 '전체'로 돌아가 모든 폴더의 상용구를 다시 쓸 수 있습니다("닫으면 '전체'로 자동 복귀" 체크박스를 끄면 고른 폴더가 그대로 유지됩니다).
- **한자 사전** — 등록해둔 한자/고유명사 데이터를 원고 이탈 없이 검색 · 삽입.
- **최근** — 최근에 열람/수정한 문서로 바로 이동.
- **클립보드** — 복사했던 텍스트 이력을 다시 꺼내 쓰는 멀티 클립보드.
- **검색** — 전체 문서 · 설정 단어를 가로질러 찾는 통합 검색.

## 기타

- **백링크** — 본문에 `[[문서명]]`을 쓰면, 같은 작품의 캐릭터 이름이나 다른 작품 제목과 일치할 때 클릭으로 바로 이동합니다.
- **소속 문서** — 캐릭터의 `소속` 값과 같은 제목의 하위 문서를 만들면 소속 값이 그 문서로 가는 링크가 되고, 그 문서 아래에 같은 소속의 인물이 카드로 자동 정리됩니다.
- **속성 정렬** — 캐릭터 목록 위의 "정렬" 선택에서 `서열`, `나이` 같은 속성값으로 오름차순/내림차순 정렬할 수 있습니다.
- **칩 필터** — 캐릭터 목록 위의 `소속`, `등급` 칩을 눌러 해당 인물만 걸러 봅니다(같은 줄은 하나라도, 다른 줄은 모두 맞아야 남음).
- **등급 배지** — 작품 편집에서 "등급 판정 축"(`위험도:R`)과 "등급 기준표"(`3:중대:도시 단위`)를 채우고 캐릭터에 같은 이름의 속성(`위험도`)을 넣으면 카드와 정보 상자에 `R 3` 배지가 붙고 작품 페이지에 기준표가 나옵니다.
- **기밀 표시** — 캐릭터에 `기밀` 속성(값이 있으면 기밀)을 넣으면 "기밀" 도장이 붙고, "기밀 가리기"를 켜면 사진과 내용이 흐려져 눌러서 하나씩 엽니다.
- **공개용 HTML 내보내기** — 작품 첫 화면의 버튼으로 작품을 읽기 전용 HTML 파일 하나로 내려받습니다(기밀 캐릭터는 가림, 제외, 그대로 중 선택).
- **보스키** — 지정한 단축키로 화면을 즉시 위장 처리(몰컴 방지 화면 잠금).
- **다크 모드 / 폰트 등 화면 설정** — 우측 상단 설정에서 글꼴 크기, 서체, 레이아웃 해상도를 개인화할 수 있습니다.
