# 캐릭터 속성값 정렬

> 대상 파일: `src/domains/character/characterSort.js`, `useCharacterSort.js`, `CharacterGrid.jsx` / 추가: 2026-10-22 / 계획서: `docs/plans/01-affiliation-page-and-sort.md`

## 무엇을 하나

작품 페이지 캐릭터 목록 위의 "정렬:" 선택에서 `서열`, `나이` 같은 속성을 골라 오름차순 또는 내림차순으로 정렬한다. "수동 순서"를 고르면 예전처럼 드래그로 정한 순서를 쓴다.

## 규칙

- 선택지는 캐릭터들이 가진 속성 이름 목록(편집기의 속성 순서)에서 값이 하나라도 있는 것만 나온다. 시스템용 속성(`_`로 시작)은 나오지 않는다.
- 비교는 두 값 모두에 숫자가 있으면 **처음 나오는 숫자**로 한다("서열 4", "22세", "6서클(신성)"). 숫자가 없거나 같으면 가나다순이다.
- 값이 없는 캐릭터는 오름차순이든 내림차순이든 **맨 뒤**에 둔다.
- 값이 같은 캐릭터끼리는 수동 순서를 유지한다.
- 정렬은 분류 그룹(관계, 소속 등) **안에서** 적용된다.
- 정렬을 켜면 카드를 끌 수 없다(화면 순서와 저장되는 수동 순서가 어긋나지 않게). 수동 순서로 되돌리면 다시 끌 수 있다.
- 선택은 작품마다 브라우저(`localStorage`, 키 `galpi-char-sort-작품번호`)에 저장된다. 서버에는 저장하지 않는다.
- 소속 인물 목록(하위 문서 아래)도 같은 정렬을 따른다.

## 용어

- **오름차순/내림차순**: 작은 값부터/큰 값부터 나열.
- **수동 순서**: 카드를 끌어 정한 순서. 정렬을 켜도 지워지지 않고 그대로 보관된다.
- **`localStorage`**: 브라우저(앱) 안에 작은 설정을 저장하는 곳.

## 구조

- `characterSort.js`: 속성값 읽기(`getPropValue`), 선택지 모으기(`collectSortKeys`), 정렬(`sortCharsByProperty`).
- `useCharacterSort.js`: 작품별 선택 상태와 저장.
- `CharacterGrid.jsx`: "정렬:" 선택과 정렬 중 드래그 끄기.
- `WorkDetailPage.jsx`: 그룹 정렬 뒤에 속성 정렬을 덮어쓴다.
