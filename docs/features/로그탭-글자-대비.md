# 로그탭 선택 탭 글자 대비

> 대상 파일: `src/domains/macro/utils/macroGenerators.js`(`createLogTabHtml`) / 수정: 2026-10-20

## 무엇을 하나

문서에 `[로그탭:색이름:본문]` 또는 `[로그탭:색이름]본문[/로그탭]`을 쓰면 탭 8개(내용, 파랑, 초록, 노랑, 빨강, 사전, 설정, 기록)가 달린 상자로 그려진다. 색이름과 같은 탭이 "선택된 탭"이 되고, 그 탭의 색으로 상자 테두리와 배경이 정해진다.

## 규칙

- **선택된 탭**: 연한 파스텔 배경 + 그 탭 고유의 진한 강조색 글자. 장르 테마가 글자색을 바꾸지 못한다.
- **선택되지 않은 탭**: 현재 테마의 패널 배경과 보조 글자색(`gt-macro-box`, `gt-macro-ink-soft`)을 따른다. 어두운 테마에서는 어두운 배경에 밝은 글자가 된다.
- **본문 상자**: 테마의 본문 글자색(`gt-macro-ink`)을 따른다. 배경은 탭 색을 아주 옅게(알파 12%) 깐 것이라 테마 배경 위에서 글자가 읽힌다.

## 용어

- **장르 테마**: 작품 분류(아포칼립스, 사이버펑크, 무협 등)에 따라 페이지 전체의 색과 글꼴을 바꾸는 스타일 묶음(`src/pages/WorkDetail/themes/*.css`).
- **`gt-macro-ink`**: 장르 테마가 매크로(로그탭, 타임라인 등) 안의 글자색을 강제로 바꿀 때 쓰는 표식(클래스). 테마 CSS에서 `!important`로 적용되므로 직접 지정한 글자색보다 우선한다.
- **대비**: 글자색과 배경색의 밝기 차이. 작을수록 읽기 어렵다(보통 4.5 이상을 권장).

## 검증

`npm test`: 선택된 탭에 `gt-macro-ink`가 없는지, 글자색이 고정 색(변수 아님)인지, 선택되지 않은 탭이 테마 패널 클래스를 유지하는지. 수정을 되돌리면 첫 번째 시험이 실패하는 것을 확인했다.
