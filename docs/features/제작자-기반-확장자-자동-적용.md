# 제작자 기반 확장자 자동 적용

> 대상 파일: `src/pages/Editor/components/WorkMetaPanel.jsx`, `src/pages/Editor/creatorExt.js` / 대문 확장자 추가: 2026-10-13

## 무엇을 하나

작품을 새로 만들거나 편집할 때 **제작자(작가) 입력칸에서 Tab 키로 빠져나가면**, 같은 제작자의 다른 작품들을 살펴서 이미지 확장자를 자동으로 채워 준다. 같은 작가는 보통 같은 형식(webp, png 등)으로 이미지를 만들기 때문에 매번 고르지 않아도 되게 한 기능이다.

| 항목 | 채우는 방식 |
|---|---|
| 캐릭터 확장자 | 같은 제작자의 작품들이 가장 많이 쓴 값으로 항상 맞춘다 |
| 대문(커버) 확장자 | 가장 많이 쓴 값으로 채우되, **이미 "없음"이 아닌 값을 골라 둔 경우에는 덮어쓰지 않는다** |

## 규칙

- 같은 제작자는 이름이 같은지로 판단한다(앞뒤 공백은 무시).
- 값이 비어 있는 작품(대문 "없음")은 세지 않는다. 같은 제작자의 작품 중 대문이 하나도 없으면 대문 확장자는 건드리지 않는다.
- 개수가 같으면 먼저 나온 확장자를 쓴다. `.png`와 `png`는 같은 값으로 센다.
- 처음 보는 제작자이거나 작품 목록을 불러오지 못하면 아무것도 바꾸지 않는다.

## 용어

- **확장자**: 이미지 파일 이름 끝의 종류 표시(`png`, `webp` 등). 작품 문서의 메타 정보(`coverExt`, `charExt`)로 저장되고, 화면이 이미지 주소를 만들 때 쓴다.
- **대문(커버) 확장자**: 작품 대표 이미지(`/img/cover/작품명.확장자`)의 확장자. "없음"이면 커버가 없는 작품으로 본다.
- **Tab 키로 빠져나감**: 입력칸에서 다음 칸으로 넘어가는 키 조작. 이때 자동 적용이 실행된다.

## 구조

- `creatorExt.js`의 `pickMostUsedExt(works, 제작자, 키)`: 제작자가 같은 작품 중 그 키(`charExt` 또는 `coverExt`)에 값이 있는 것만 세어 최다 값을 돌려주는 순수 함수.
- `WorkMetaPanel.jsx`의 `handleCreatorTab`: 작품 목록을 한 번 불러와 두 확장자를 계산하고, 한 번의 상태 갱신으로 반영한다.

## 검증

`npm test`: 최다 확장자 계산(제작자 구분, 빈 값 제외, 동률, 점/공백 정리, 깨진 메타), Tab을 눌렀을 때 두 확장자가 함께 채워지는지, 이미 고른 대문 확장자를 덮어쓰지 않는지, 대문이 없는 제작자와 처음 보는 제작자, 조회 실패.
