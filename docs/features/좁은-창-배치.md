# 좁은 창 배치 (화면 반으로 나눠 쓸 때)

> 대상 파일: `src/pages/WorkDetail/WorkDetail.module.css`, `src/domains/character/CharacterGrid.jsx` / 수정: 2026-10-23

## 무엇을 하나

갈피를 화면 절반 크기 창(너비 약 960px)으로 쓸 때도 작품 페이지가 깨끗하게 보이게 한다. 특히 "등장인물 목록" 머리말의 제목, 선택 상자, 버튼이 글자 단위로 줄바꿈되지 않는다.

## 규칙

- **머리말(`sectionHeader`)은 줄 단위로만 넘어간다.** 자리가 모자라면 오른쪽 버튼 묶음(이미지 위치 조정, 새 캐릭터 추가)이 다음 줄 오른쪽 끝으로 내려간다. 글자는 쪼개지지 않는다.
- 등장인물 목록 머리말의 제목, "분류 기준:", "정렬:" 라벨, "새 캐릭터 추가" 버튼은 `white-space: nowrap`이다.
- **너비 1199px 이하에서, 캐릭터를 고르지 않아 오른쪽 정보 상자가 비어 있으면 그 자리(340px)를 접는다.** 960px 창에서 본문이 약 550px에서 약 920px로 넓어진다. 캐릭터를 고르면 정보 상자가 나타나 본문이 다시 좁아지고, 머리말은 두 줄로 나뉜다.
- 1200px 이상의 넓은 창에서는 정보 상자 자리를 그대로 둔다(캐릭터를 고를 때 본문 폭이 갑자기 변하지 않게).

## 용어

- **flex-wrap**: 한 줄에 다 안 들어가면 칸을 통째로 다음 줄로 넘기는 배치 설정.
- **white-space: nowrap**: 글자를 줄바꿈하지 않는 설정.
- **미디어 쿼리(`@media`)**: 창 너비에 따라 다른 스타일을 적용하는 규칙.
- **`:empty`**: 안에 아무 내용이 없는 요소만 고르는 선택자.

## 검증

`npm test`: 머리말의 줄바꿈 허용과 `nowrap`, 좁은 창 미디어 쿼리와 `:empty` 규칙, 넓은 창에서 자리 유지. 수정을 되돌리면 4개가 실패하는 것을 확인했다. 브라우저에서 창 너비 960px로 실제 레이아웃을 만들어 확인했다(고치기 전: 제목 52px로 두 줄, 본문 550px / 고친 뒤: 정보 상자가 비면 본문 920px, 선택하면 550px에 머리말 두 줄). 실제 작품 데이터로 앱을 열어 보지는 못했다.
