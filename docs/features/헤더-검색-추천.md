# 헤더 검색 추천

> 대상 파일: `src/components/layout/search/` (`HeaderSearch.jsx`, `searchSuggest.js`, `searchSettings.js`), `GlobalContextMenu.jsx` / 추가: 2026-10-09

## 무엇을 하나

화면 맨 위 검색창에 글자를 입력하면, 관련 작품이 **창 아래로 목록처럼** 추천된다. 항목을 누르거나 화살표로 고르고 엔터를 치면 그 작품 페이지로 이동한다. 현재 화면(홈의 분류 필터 등)과 상관없이 항상 전체 작품에서 찾는다.

## 사용법

- 입력: 제목, 약칭, 장르 어느 쪽이든 일부만 써도 찾는다. 대소문자는 구분하지 않는다.
- 이동: 위/아래 화살표로 고르고 엔터. 고르지 않고 엔터를 치면 목록의 가장 위 작품으로 간다. 마우스로 항목을 눌러도 된다.
- 닫기: Esc 또는 검색창 바깥을 누른다.
- 추천 순서: 제목 또는 약칭이 정확히 같음 > 제목이 입력으로 시작 > 약칭이 입력으로 시작 > 제목에 포함 > 약칭에 포함 > 장르에 포함. 같은 단계 안에서는 제목 가나다순이며 최대 8개를 보여 준다.

## 숨김 분류 작품을 넣을지 끌지

1. 아무 화면에서나 **Shift를 누른 채 우클릭**한다.
2. "Ctrl+S 무시" 바로 아래의 **"숨김 작품 검색 켜짐/꺼짐"** 항목을 누르면 켜고 끌 수 있다.
3. 기본은 **켜짐**: 숨김 분류에 걸린 작품도 추천에 나오고 "숨김 분류" 표시가 붙는다.
4. **꺼짐**: 숨김 분류 작품은 추천과 엔터 이동에서 빠진다.
5. 설정은 저장되어 다음 실행에도 유지되고, 검색창이 열려 있어도 바로 반영된다.

## 용어

- **추천(자동완성)**: 입력한 글자와 관련된 후보를 미리 보여 주는 기능.
- **숨김 분류**: 메인 화면에서 숨기도록 정해 둔 분류(비밀 금고). 목록의 원본은 서버 DB(`/api/hidden-categories`)에 있다.
- **약칭(alias)**: 작품 설명 맨 위 메타 정보(`[META_DATA:{"alias":"..."}]`)에 적어 두는 짧은 이름.
- **localStorage**: 브라우저(창)가 주소별로 저장하는 작은 저장소. 이 설정은 `galpi-search-include-hidden` 키에 저장된다.

## 구조

- `HeaderSearch.jsx`: 화면과 키보드 처리. 작품 목록과 숨김 분류를 서버에서 불러온다(1분이 지나면 검색창을 누를 때 다시 불러온다).
- `searchSuggest.js`: 후보 만들기(`buildCandidates`)와 추천 순위(`rankSuggestions`). 화면과 무관한 순수 함수라 테스트로 검증한다.
- `searchSettings.js`: 포함 여부 저장과 변경 알림 이벤트(`galpi-search-settings-changed`).
