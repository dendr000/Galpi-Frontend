# SVG 아이콘 (이모티콘 대체)

> 대상 파일: `src/assets/icons/*.svg`, `src/components/common/icons/Icon.jsx`, `iconRegistry.js` / 시작: 2026-10-26 (1차)

## 무엇을 하나

화면에 보이던 이모티콘(그림 문자)을 SVG 아이콘으로 바꾼다. 이모티콘은 PC 와 글꼴에 따라 모양과 색이 달라지고 라이트/다크에서 안 읽힐 수 있지만, SVG 아이콘은 **주변 글자색**과 **글자 크기**를 그대로 따라 어디서나 같은 모양으로 보인다.

## 사용법

- 화면(React)에서: `<Icon name="trash" />`. 글자 앞에 붙일 때는 `<Icon name="trash" lead />`(글자와 살짝 띄움), 크기는 `size={20}`(px), 설명은 `title`.
- 문자열 HTML(매크로 위젯, 책갈피 등 React 밖)에서: `iconHtml('bookmark')`.
- 새 아이콘은 `src/assets/icons/이름.svg` 로 만든다(24 격자, `fill="currentColor"`, 첫 줄 저작권 주석). 먼저 공용 아이콘 폴더에 있는지 찾아 복사한다.

## 규칙

- 이름은 모양이 아니라 의미로 짓는다(예: 삭제는 `trash`). 등록되지 않은 이름은 아무것도 그리지 않는다.
- 알림창과 토스트처럼 글자만 나오는 곳에는 아이콘을 못 넣으므로 이모티콘을 빼고 글자만 남긴다.
- 아이콘 파일 규격(24 격자, 글자색 채움, 고정 색과 스크립트 없음)은 테스트(`iconRegistry.test.jsx`)가 모든 파일에 대해 검사한다.
- 이미 저장된 옛 메모 속 책갈피 이모티콘도 읽을 때 이름에서 걸러 낸다.

## 현재 상태

1차: 우클릭 메뉴, 클립보드 창, 문서 트리와 목차와 하위 문서 목록, 작품 표지 버튼, 메모 링크 창과 책갈피, 문단 접기 버튼, 매크로 편집기와 차트 제목, 보스키 화면 등. **남은 곳**: 로그인, 홈(즐겨찾기), 404, 소설 보기, 에디터 검색과 백링크 창, 일괄 편집 도구, 관계도 편집기, 매크로 위젯과 오류 문구(`macroGenerators.js`, `macroBuilders.js`), 테마 CSS 장식 기호(방사능, 다이아). 모두 바꾸면 소스에 이모티콘이 남지 않았는지 검사하는 테스트를 추가한다.

## 용어

- **SVG**: 도형 좌표로 그리는 그림 형식. 크게 해도 깨지지 않는다.
- **`currentColor`**: "지금 글자색을 그대로 쓴다"는 색 값.
- **이모티콘(이모지)**: 글자처럼 쓰이는 그림 문자.
