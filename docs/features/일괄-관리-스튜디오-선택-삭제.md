# 일괄 관리 스튜디오: 선택 삭제

> 대상 파일: `src/pages/BulkStudio/useBulkStudioData.js`(`removeCheckedRows`), `BulkToolbar.jsx` / 추가: 2026-11-04

## 무엇을 하나

스튜디오 표에서 왼쪽 체크칸으로 고른 캐릭터를 한 번에 지운다. "붙여넣기로 추가"로 잘못 만든 인물을 하나씩 ✖로 지우던 일을 줄인다.

## 쓰는 법

1. 지울 행의 체크칸을 누른다. shift+클릭은 범위 선택, 맨 위 체크칸은 전체 선택이다.
2. 툴바 오른쪽 "선택 삭제 (N)" 버튼을 누른다. 체크한 행이 없으면 버튼이 꺼져 있다.
3. 확인창에서 인원 수를 확인하고 승인한다.
4. **"일괄 저장"을 눌러야 서버에서도 지워진다.** 저장 전에는 화면에서만 지워진 상태다.

## 규칙

- 아직 저장하지 않은 새 행은 저장 요청이 없고 그냥 사라진다.
- 이미 저장돼 있던 인물은 "일괄 저장" 때 삭제 요청이 간다(기존 행 삭제와 같은 방식). 삭제는 휴지통이 아니라 서버 삭제 API를 쓴다.
- 저장 전에 작품을 다시 선택해 불러오면 지운 인물이 되살아난다.
- 지운 뒤에는 shift+클릭 범위 기준점을 비운다(행 번호가 바뀌므로).

## 왜 "붙여넣기로 추가"로 고치지 않나

사용자 요청: 붙여넣기 창에서 내용을 고쳐 다시 "반영 추가"를 누르면 앞서 추가한 인물을 고치는 것이 아니라 완전히 새로운 캐릭터들로 추가되어, 잘못된 것을 고칠 수 없었다. 그래서 잘못 추가한 인물을 먼저 한 번에 지우는 수단을 두었다. 값만 고치려면 표에서 직접 고치거나 "찾아 바꾸기"를 쓴다.

## 용어

- **체크칸**: 표 왼쪽의 선택 상자. 일괄 적용, 선택 삭제의 대상을 정한다.
- **일괄 저장**: 표의 내용을 서버에 반영하는 버튼. 표에서 빠진 기존 인물의 삭제도 이때 일어난다.

## 검증

`npm test`: 체크한 행만 삭제, 확인창에 인원 수 표시, 취소하면 그대로, 체크 없으면 안내만, 전체 삭제, 삭제 뒤 shift 선택 안전, 저장 시 삭제 요청 대상(기존 인물만), 툴바 버튼의 인원 수/비활성/클릭. 변이 검사 3가지(기준점 미초기화, 체크 안 한 행만 삭제, 확인 생략)에서 각각 테스트가 실패함을 확인했다. 실제 화면은 백엔드를 띄우지 않아 보지 못했다.
