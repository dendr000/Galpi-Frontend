# 장르 테마 글자 대비

> 대상 파일: `src/pages/WorkDetail/themes/*.css`, 시험 도구 `themeContrast.js` / 수정: 2026-10-20

## 무엇을 하나

작품 분류(장르)마다 페이지 색과 글꼴을 바꾸는 테마 CSS가 21개 있다. 테마마다 라이트/다크 모드에 따라 일부 색 변수가 바뀌는데, 글자색과 배경색 중 한쪽만 바뀌면 글자가 배경에 묻힌다. 이를 막기 위해 글자와 배경의 **대비**를 계산해 시험한다.

## 규칙

- 글자와 배경 대비는 **4.5 이상**을 목표로 한다.
- 배경이 모드와 무관하게 고정이면 글자색도 고정 변수를 쓴다(예: 만화 테마 노란 버튼은 `--cx-on-yellow`).
- 한 모드에서만 문제면 `[data-theme="dark"]` 접두 규칙으로 그 모드만 덮어쓴다(라이트 모드를 건드리지 않는다).
- 시험으로 지키는 곳: 만화 노란 버튼(라이트·다크), 성황당 푸터 호버, 무협 수묵·헌터 홀로그램 다크 강조 배경.

## 용어

- **대비(contrast ratio)**: 두 색의 밝기 차이를 1~21 사이 숫자로 나타낸 값. 클수록 잘 읽힌다. 글자 읽기에는 4.5 이상이 권장 기준이다.
- **반투명 패널(rgba)**: 투명도가 있는 색. 아래 배경과 섞여 실제 색이 정해지므로, 시험은 아래 배경 몇 가지 위에 올려 계산한다.
- **`gt-macro-accent-bg`**: 매크로(로그탭 등)의 강조 배경과 그 위 글자색을 정하는 테마용 표식(클래스).

## 구조

- `themeContrast.js`: 테마 CSS를 읽어 변수(`var()`), 16진수, `rgba()`를 색으로 풀고, 선택자의 최종 스타일(다크 모드 덮어쓰기 반영)과 대비를 계산한다.
- `themeContrast.test.js`: 위 "시험으로 지키는 곳"을 검사한다.

## 검증

`npm test`. CSS 수정을 되돌리면 5개 시험이 실패하는 것을 확인했다. 계산은 정적이라 그라데이션 위 글자, 이미지 위 글자, 실제 화면 렌더링은 보지 않는다.
