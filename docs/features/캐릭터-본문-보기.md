# 캐릭터 본문 보기 (자동 이동, 그리드로, 큰 창, 검색, 주변 캐릭터 띠)

> 대상 파일: `src/domains/character/useGridSelectScroll.js`, `charViewSettings.js`, `CharacterDetailSection.jsx` / 추가: 2026-11-05 / 계획서: `docs/plans/03-character-view-modal.md`

## 무엇을 하나

작품 페이지에서 캐릭터 본문을 보기 쉽게 한다. 1단계(자동 이동, 그리드로)와 2단계(큰 창, 보기 설정)를 다룬다.

## 동작

- **자동 이동**: 캐릭터 그리드의 카드를 눌러 선택하면, 선택이 화면에 반영된 뒤 아래 본문 구역(`character-detail-section`)의 위로 부드럽게 이동한다.
- **이동하지 않는 경우**: 이미 선택한 카드를 다시 눌러 해제할 때, 맨 아래 "캐릭터 빠른 이동" 이름 바를 누를 때, 가려진(기밀) 카드의 첫 클릭(선택이 되지 않음), 문서(소속 하위 문서) 화면을 보는 중.
- **그리드로**: 본문 제목 줄의 버튼. 누르면 그 캐릭터의 카드(`char-card-번호`)가 화면 가운데 오게 이동한다. 폼 전환으로 바뀐 캐릭터는 기준 캐릭터의 카드로 돌아온다.

## 설정

앱 전체에 하나만 두고 이 PC의 `localStorage` 키 `galpi.charView` 에 JSON 으로 저장한다.

| 항목 | 기본값 | 뜻 |
|---|---|---|
| `autoScroll` | 켬 | 카드를 선택하면 본문으로 이동 |
| `dblClickModal` | 켬 | 카드를 더블클릭하면 큰 창으로 열기 |

- 값이 없거나 깨졌거나 저장소를 쓸 수 없으면 기본값을 쓴다.
- 캐릭터 목록 위 "보기 설정"(톱니 버튼) 메뉴에서 두 항목을 켜고 끈다. 바꾸면 바로 저장된다.

## 큰 창

- **여는 법**: 카드 왼쪽 위의 확대 버튼, 또는 카드 더블클릭(설정에서 끌 수 있음). 열 때 그 캐릭터가 선택되므로 닫은 뒤 아래 본문, 인포박스와 어긋나지 않는다. 카드 한 번 클릭은 선택만 한다(더블클릭의 두 번째 클릭은 선택 해제를 하지 않는다).
- **화면**: 위쪽에 이전, 다음 버튼, 이름, `3 / 12` 순번, 닫기. 왼쪽에 본문, 오른쪽에 인포박스(폼 전환 등 평소 인포박스 기능 그대로). 본문은 캐릭터를 넘길 때마다 맨 위부터 보인다.
- **검색**: 위쪽 검색 상자에 이름 일부를 치면 일치하는 캐릭터가 최대 8명까지 목록으로 뜬다. 이름이 입력으로 시작하는 캐릭터가 먼저, 나머지는 그리드 순서대로 나온다. 위/아래 화살표로 고르고 Enter 또는 클릭으로 이동하며, 이동하면 입력과 목록이 비워지고 커서가 큰 창으로 돌아와 바로 방향키로 넘길 수 있다. Esc 는 입력부터 지우고, 입력이 비어 있을 때의 Esc 가 큰 창을 닫는다. 한글 조합 중의 Enter 는 이동하지 않는다. 큰 창에서 `/` 를 누르면 검색 상자로 커서가 간다(입력칸 안에서는 그냥 글자). 가려진 기밀 캐릭터는 이름으로도 찾을 수 없다.
- **주변 캐릭터 띠**: 아래쪽에 그리드 순서대로 모든 캐릭터가 이미지와 이름으로 한 줄로 늘어선다(옆으로 스크롤). 지금 보는 캐릭터는 그 캐릭터의 테마 색 테두리로 표시되고 넘길 때마다 띠의 가운데로 맞춰진다. 누르면 그 캐릭터로 넘어간다. 이미지는 그리드 카드와 같은 기본 이미지 주소를 쓰고, 불러오지 못하면 이미지를 숨기고 이름의 첫 글자를 테마 색 바탕에 보여 준다.
- **하단 푸터**: 화면 아래에는 항상 떠 있는 푸터(높이 48px, 층 8000)가 있어 큰 창(층 3000)의 아래쪽을 덮었다. 큰 창의 아래 여백을 푸터 높이(52px)만큼 늘려 주변 캐릭터 띠까지 보이게 했다.
- **인포박스 위치**: 평소 화면의 인포박스는 스크롤을 따라다니도록(`sticky`) 되어 있는데, 큰 창 안에서 그대로 두면 오른쪽 칸 위에 큰 빈칸이 생겼다. 큰 창 안(`.char-modal-aside`)에서는 따라다니기와 높이 제한을 풀어 오른쪽 칸 전체가 스크롤되게 했다.
- **키**: 왼쪽, 오른쪽 방향키는 이전, 다음(처음, 끝에서는 멈춤), Esc는 닫기. 입력칸에 커서가 있거나, 한글 조합 중이거나, Ctrl/Alt/Shift/Meta를 누른 상태이거나, 이미 다른 곳에서 처리한 키면 반응하지 않는다.
- **넘기는 순서**: 그리드에 보이는 그룹 순서 그대로(필터, 정렬 반영). 여러 그룹에 든 캐릭터는 한 번만, 가려진 기밀 캐릭터는 뺀다. 가려진 기밀 카드에는 확대 버튼이 없고 더블클릭으로도 열리지 않는다.
- **닫기**: Esc, 닫기 버튼, 어두운 배경 누르기(글자를 드래그해 선택하다 바깥에서 놓는 경우는 닫지 않음). 열려 있는 동안 뒤쪽 페이지 스크롤은 잠긴다.
- **본문 링크**: 큰 창 안의 `[[이름]]` 링크를 누르면 큰 창을 닫고 평소 링크 동작을 한다.
- **목차**: 큰 창은 본문 구역과 같은 글을 한 번 더 그리므로, 목차용 제목 스캔은 큰 창 안(`data-char-modal`)의 제목을 건너뛴다. 빼지 않으면 목차에 같은 항목이 겹친다.
- **하위 문서 화면**에서는 큰 창을 쓰지 않는다.
- 큰 창은 화면 맨 위 층(`body` 바로 아래)에 그려지므로 장르 테마의 본문 꾸밈은 적용되지 않고 기본 모양으로 보인다.

## 용어

- **자동 이동**: 선택한 뒤 화면을 본문 위치로 내려 주는 동작.
- **스크롤**: 화면을 위아래로 움직이는 것.
- **콤보박스(combobox)**: 글자를 치면 아래에 후보 목록이 뜨는 입력 방식. 화살표로 후보를 고르고 Enter 로 확정한다.
- **큰 창(모달)**: 현재 화면 위에 겹쳐 뜨는 창. 닫기 전까지 뒤쪽 화면은 조작되지 않는다.
- **`localStorage`**: 브라우저(앱)가 이 PC에 값을 저장해 두는 곳. 서버로 가지 않는다.

## 검증

`npm test`: 설정(기본값, 저장, 일부 변경, 깨진 값, 저장소 사용 불가), 자동 이동(선택 후 본문이 그려진 뒤 이동, 해제와 설정 끔에서는 이동 없음, 본문 구역이 없어도 오류 없음), 카드로 돌아가기, "그리드로" 버튼. 변이 검사 3가지(해제도 이동, 설정 무시, 본문이 그려지기 전에 이동)에서 각각 테스트가 실패함을 확인했다. 실제 화면 스크롤은 백엔드 없이 확인하지 못했다.

큰 창: 열림과 내용, 방향키 이동(양끝 멈춤, 하나뿐일 때), 입력칸, 글자 조합 중, 보조키, 이미 처리된 키 무시, Esc, 닫기 버튼, 바깥 누르기, 안쪽 누르기와 닫힌 뒤 무반응, 스크롤 잠금과 복원. 그리드(확대 버튼, 더블클릭, detail 2 클릭, 설정 끔, 기밀 카드), 설정 메뉴(열기, 저장, 닫기, Esc), 작품 페이지 연결(열기, 기밀 제외, 링크, 하위 문서), 목차 스캔 제외. 변이 검사 6가지(조합 중 무시, 입력칸 무시, 끝에서 돌아가기, 바깥 누르기 판정, 두 번째 클릭 처리, 기밀 더블클릭)에서 각각 테스트가 실패함을 확인했다. 실제 화면은 백엔드 없이 확인하지 못했다.

검색과 주변 캐릭터 띠: 이름 포함 검색(앞부분 일치 우선, 대소문자 무시, 공백, 개수 제한, 빈 입력), 테마 색 읽기(이중 JSON, 깨진 JSON), 검색 상자(목록, 없음 안내, Enter, 화살표 양끝, 한글 조합, 결과 클릭, Esc 두 단계, 입력칸 안 방향키와 `/`, 결과 상자 빈 곳 클릭), 띠(전체 표시, 현재 표시, 클릭 이동, 이미지 오류 대체, 주소 없음), 작품 페이지 연결(이미지 주소가 파일명 금지 글자를 바꾼 규칙을 따름, 기밀 캐릭터 제외, 검색 후 이동). 변이 검사 9가지(앞부분 일치 우선, 한글 조합 무시, Esc 처리, 화살표 양끝, 현재 표시, 입력칸 안 `/`, 이미지 오류 대체, 파일명 규칙, 결과 상자 포커스 유지)에서 각각 테스트가 실패함을 확인했다. 실제 화면 모양(빈칸 해소, 띠 디자인)은 백엔드 없이 확인하지 못해 눈으로 확인하지 못했다.
