# 그룹에서 숨길 값

> 대상 파일: `src/domains/character/groupHide.js`, `src/domains/character/characterGroups.js`, `useCharacterDrag.js`, `src/pages/Editor/components/WorkMetaPanel.jsx`, `src/pages/Editor/hooks/useEditorFetch.js`, `useEditorSave.js`, `useEditorState.js`, `src/pages/WorkDetail/WorkDetailPage.jsx`, `src/domains/work/export/prepareExportModel.js` / 추가: 2026-11-06 / 계획서: `docs/plans/04-hide-group-values.md`

## 무엇을 하나

작품 페이지 캐릭터 그리드의 그룹(소속별, 등급별 등)에서 **특정 값은 그룹으로 만들지 않게** 작품마다 정한다. 소속이 너무 세분화되어 `북부, 1조, 2조`처럼 값이 여럿인 캐릭터가 여러 그룹에 반복해서 나올 때, 쓰지 않을 값만 골라 뺀다.

예: 소속 숨김에 `1조, 2조`를 쓰면 `북부, 1조`인 캐릭터는 북부 그룹에만 나오고, `1조`만 가진 캐릭터는 "미분류"에 나온다. `1조`, `2조` 그룹은 생기지 않는다.

## 어디서 정하나

작품 편집 화면의 "문서 속성 및 개요 설정" > "상세 속성 설정" 안 **"그룹에서 숨길 값"** 칸. 한 줄에 하나, `속성명: 값1, 값2` 형식이다(그룹 정렬 순서 칸과 같은 모양).

```text
소속: 1조, 2조
등급: D급
```

저장하면 작품 정보(메타)의 `_groupHide` 에 `{ 소속: ["1조","2조"], 등급: ["D급"] }` 로 들어간다. 칸을 모두 지우면(또는 형식이 맞는 줄이 하나도 없으면) 저장된 값도 지워진다.

## 규칙

- **속성(분류 기준)마다 따로 적용된다.** 위 예에서 `소속` 줄은 "소속별"로 볼 때만, `등급` 줄은 "등급별"로 볼 때만 쓰인다.
- **숨김을 먼저 적용하고, 그 뒤에 "여러 값일 때 그룹 표시"(첫 번째, 마지막)를 센다.** 소속이 `1조, 북부, 사교`이고 `1조`를 숨기면 "첫 번째 값"은 `북부`다. (`*`로 시작하는 값을 빼는 것과 같은 순서)
- **값이 모두 숨겨진 캐릭터는 "미분류"로 간다.** 그리드에서 사라져 찾을 수 없는 캐릭터가 생기지 않게 하려는 것이고, 값이 아예 없는 캐릭터와 같은 취급이다. 그래서 `미분류` 자체는 숨길 수 없다(써도 무시된다).
- 값은 앞뒤 공백을 다듬고, 대소문자를 구분해 그룹 이름과 똑같이 맞춘다.
- 같은 속성을 여러 줄에 써도 합쳐서 읽고, 쌍점(`:`)이 값 안에 있으면 첫 쌍점 뒤를 모두 값으로 본다. 쌍점이 없거나 이름 또는 값이 빈 줄은 건너뛴다.
- 화면 그리드, 카드 끌기(그룹 안 순서 바꾸기), 공개용 HTML 내보내기가 같은 기준을 쓴다.
- 그룹 묶기에만 영향을 준다. 아래는 그대로다.
  - 정보 상자와 카드에 보이는 `소속` 값 자체
  - 칩 필터의 `소속` 칩
  - 하위 문서의 "소속 인물" 목록
  - 캐릭터 본문 큰 창에서 넘기는 순서에는 그리드에 보이는 순서가 그대로 반영된다.

## 용어

- **분류 기준**: 작품 페이지 캐릭터 목록 위에서 고르는 "분류 기준:" 선택(소속, 관계 등).
- **메타(META_DATA)**: 작품 설명 맨 앞에 JSON으로 저장되는 작품 설정 묶음.
- **미분류**: 값이 없거나 보이는 값이 하나도 남지 않은 캐릭터가 모이는 그룹.
