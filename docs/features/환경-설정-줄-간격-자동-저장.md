# 환경 설정: 줄 간격과 자동 저장

> 대상 파일: `src/store/useSettingStore.js`, `src/utils/layoutWidth.js`(설정 옮기기), `src/App.jsx`, `src/pages/WorkDetail/WorkDetail.module.css`, `src/pages/Editor/hooks/autoSaveDelay.js`, `src/pages/Editor/hooks/useEditorAutoSave.js`, `src/components/common/SettingModal.jsx` / 추가: 2026-11-10

## 무엇을 하나

환경 설정(톱니바퀴)에서 고른 두 값이 실제 화면에 적용된다.

- **줄 간격**(화면 및 텍스트 탭): 문서 본문(작품 페이지, 하위 문서, 편집기 미리보기)의 줄 사이 간격. 1.2 에서 2.5 까지, 기본 1.8.
- **자동 저장**(에디터 및 단축키 탭): 편집기에서 입력이 멈춘 뒤 저장하기까지의 시간. "입력 후 3초(기본)", "30초", "1분".

자동 저장은 끌 수 없다. 저장하지 않은 글을 잃지 않기 위해서다. 새 문서를 처음 저장하기 전, 제목이 비어 있을 때는 예전처럼 자동 저장하지 않는다.

## 알아 둘 것

- 예전 "자동 저장: 사용 안함" 은 실제로는 꺼지지 않고 3초 뒤에 저장하고 있었다. 이미 그렇게 저장돼 있던 설정은 "입력 후 3초" 로 바뀐다. 줄 간격 기본값도 한 번도 적용된 적 없던 1.6 에서 본문이 실제로 쓰던 1.8 로 옮겨서, 업데이트해도 본문 모양은 그대로다.
- 30초나 1분을 고르면 편집기 저장 상태 표시가 그 시간 동안 "저장 중" 으로 보일 수 있다(저장 대기 표시).
- 편집기 입력칸의 줄 간격(1.7)과 글자 크기, 글꼴 설정은 이번에 바꾸지 않았다. 글자 크기와 글꼴은 지금도 편집기 입력칸에만 적용된다.

## 구조(개발자용)

- `useSettingStore` — `lineHeight`(기본 `'1.8'`), `autoSaveInterval`(기본 `'3'`, 초).
- `App.jsx` — `lineHeight` 를 최상위 칸의 CSS 변수 `--markdown-line-height` 로 내려 준다. `.markdown-body` 가 `line-height: var(--markdown-line-height, 1.8)` 로 쓴다.
- `autoSaveDelay.js` — `getAutoSaveDelayMs(설정값)`: 양수만 인정하고 그 밖의 값(옛 `"0"` 포함)은 3초. `AUTO_SAVE_OPTIONS` 는 설정 화면의 선택지.
- `useEditorAutoSave` — 설정 값을 읽어 타이머 시간으로 쓴다.
- `migrateSettings`(설정 저장 버전 2) — 옛 `lineHeight '1.6'` 은 `'1.8'`, `autoSaveInterval '0'` 은 `'3'` 으로. 사용자가 고른 다른 값은 그대로.

## 용어

- **설정 저장 버전**: 설정 형식이나 기본값이 바뀔 때 올리는 번호. 저장돼 있던 옛 설정을 한 번만 새 기준으로 옮기는 데 쓴다.
- **디바운스(입력 멈춘 뒤 저장)**: 입력할 때마다 타이머를 다시 시작해서, 마지막 입력 뒤 정해진 시간이 지나야 저장하는 방식.

## 확인한 것

- 시험: 줄 간격 슬라이더, 자동 저장 선택지, 옛 설정 옮기기, 자동 저장 지연(3초, 30초, 옛 `"0"`), 입력을 계속하면 한 번만 저장, 새 문서와 빈 제목은 저장 안 함.
- 실제 편집기와 작품 페이지 화면은 백엔드가 필요해 사용자가 직접 확인해야 한다.
