# 기밀 표시

> 대상 파일: `src/domains/character/classified.js`, `useClassifiedMask.js`, `ClassifiedStamp.jsx`, `CharacterGrid.jsx`, `CharacterInfobox.jsx`, `PageMemberList.jsx` / 추가: 2026-10-22 / 계획서: `docs/plans/02-badges-classified-filter-export.md`

## 무엇을 하나

캐릭터를 "기밀"로 표시하면 "기밀" 도장이 붙고, 필요할 때 사진과 내용을 흐리게 가렸다가 눌러서 연다. 공개용으로 보여 줄 때 특정 인물을 바로 노출하지 않으려는 용도다.

## 사용법

1. 캐릭터 편집(또는 일괄 편집)에서 `기밀`이라는 이름의 속성을 추가하고 값을 넣는다(예: `Y`, `기밀`, `1급`). 별도 입력 화면은 없다.
2. 작품 페이지에서 그 캐릭터 카드, 정보 상자, 소속 인물 목록에 "기밀" 도장이 붙는다.
3. 캐릭터 목록 위에 "기밀 가리기" 선택이 나타난다(기밀 캐릭터가 하나라도 있을 때만). 켜면 기밀 캐릭터의 사진, 속성, 등급 배지가 흐려진다.
4. 흐려진 카드를 한 번 누르면 그 캐릭터만 열린다(이때는 선택하지 않고 열람만 한다). 이미 선택된 캐릭터가 가려져 있으면 정보 상자의 "기밀 열람" 버튼으로 연다.

## 규칙

- 기밀 판정: `기밀` 속성 값이 비어 있지 않고 `아니오`, `아니요`, `아님`, `N`, `No`, `false`, `0`, `x`, `없음`, `해제`(대소문자와 공백 무시)가 아니면 기밀이다.
- 도장은 가리기 상태와 무관하게 항상 보인다. 흐림은 "기밀 가리기"를 켰을 때만 적용된다.
- 가리기 켜짐 여부는 작품별로 브라우저에 저장된다(기본 꺼짐). **열람 기록은 저장하지 않아** 화면을 다시 열거나 가리기를 껐다 켜면 다시 가려진다.
- 가려진 동안에는 소속 링크가 동작하지 않는다(내용이 새지 않게). 수정, 삭제 버튼은 그대로 쓸 수 있다.
- 도장 색은 테마와 무관한 고정 색(흰 바탕, 진한 빨강)이라 어두운 장르 테마에서도 읽힌다.
- 이름은 가려지지 않는다.

## 용어

- **도장(스탬프)**: 카드 모서리에 비스듬히 붙는 "기밀" 표시.
- **흐리게 가림(블러)**: 내용을 알아보지 못하게 뿌옇게 만드는 효과.
- **열람**: 가려진 캐릭터를 이번 화면에서만 보이게 여는 것.

## 구조

- `classified.js`: 기밀 판정(`isClassified`)과 기본값.
- `useClassifiedMask.js`: 가리기 켜짐(저장), 열람 기록(화면 한정), 가려짐 판정을 가진 훅.
- `ClassifiedStamp.jsx`: 도장. 그리드, 정보 상자, 소속 인물 목록이 같은 상태 객체(`classified`)를 받는다.
