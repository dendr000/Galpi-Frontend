# 유저노트 폴더 새 메모 자동 내용

> 대상 파일: `src/domains/memo/shared/utils/newMemoTemplate.js`, `src/domains/memo/shared/utils/foldBoxHtml.js`, `src/domains/memo/fab/FabMemoModal.jsx`, `src/domains/memo/page/hooks/core/usePageTab.js` / 추가: 2026-10-14

## 무엇을 하나

메모장에서 이름이 **유저노트**인 폴더에 새 메모를 만들면, 빈 화면 대신 아래 내용이 미리 들어간 상태로 열린다.

| 줄 | 내용 |
|---|---|
| 1 | 접기 박스, 제목 "대화 프로필" |
| 2 | 접기 박스, 제목 "유저노트" |
| 3 | 빈 줄 (바로 이어서 글을 쓸 수 있는 자리) |

접기 박스의 모양과 동작은 에디터 툴바의 "접기 박스 삽입" 버튼으로 넣는 것과 같다. 제목은 미리 채워져 있고, 상자 안쪽 내용은 비어 있다.

## 적용 범위

- 플로팅 메모장(FAB 모달)의 "새 메모"와 메모 페이지의 "새 메모" 탭 모두 적용된다.
- 폴더 경로의 **마지막 이름**이 `유저노트`이면 적용한다. 최상위 `유저노트`뿐 아니라 `채팅/유저노트` 같은 경우도 포함한다.
- `유저노트/하위`처럼 그 안의 하위 폴더나 `유저노트2`, `내유저노트` 같은 비슷한 이름은 적용하지 않는다.
- 다른 폴더의 새 메모는 기존처럼 본문이 비어 있다.
- **새 메모를 만들 때 한 번만** 채운다. 이미 있는 메모를 이 폴더로 옮기거나 열어 보는 것으로는 내용이 바뀌지 않는다.

## 용어

- **접기 박스**: 제목을 눌러 내용을 접고 펼 수 있는 상자(HTML의 `details` 요소). 긴 정보를 숨겨 두는 데 쓴다.
- **빈 줄**: 내용이 없는 한 줄(`<div><br></div>`). 접기 박스 아래에서 글을 이어 쓸 수 있게 둔다.
- **순수 함수**: 같은 입력이면 항상 같은 결과를 돌려주고 화면이나 저장소를 건드리지 않는 함수. 그래서 테스트하기 쉽다.

## 구조

- `foldBoxHtml.js`의 `buildFoldBoxHtml(제목)`: 접기 박스 HTML 하나를 만든다. 툴바의 삽입 버튼도 이 함수를 쓰므로 두 곳의 모양이 항상 같다. 제목의 `<`, `>`, `&`, `"`는 글자 그대로 들어가도록 처리한다.
- `newMemoTemplate.js`의 `getNewMemoContent(폴더)`: 폴더가 유저노트면 위 내용을, 아니면 빈 문자열을 돌려준다.
- 새 메모를 만드는 두 곳(`FabMemoModal.jsx`의 `handleCreateMemo`, `usePageTab.js`의 `handleOpenTab`)이 본문을 정할 때 이 함수를 부른다.

## 검증

`npm test`: 접기 박스 제목 채우기와 특수문자 처리, 유저노트 폴더 판별(최상위·중첩·하위 폴더·비슷한 이름·빈 값), 1~3줄 구성과 순서, 두 새 메모 경로(플로팅 메모장, 메모 페이지)에서 유저노트 폴더만 내용이 채워지는지. 툴바의 접기 박스 HTML이 변경 전과 글자 단위로 같은지도 한 번 비교했다.
