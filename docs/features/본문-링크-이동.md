# 본문 [[이름]] 링크 이동

> 대상 파일: `src/domains/work/backlink.js`, `useWorkBacklink.js`, `src/pages/WorkDetail/WorkDetailPage.jsx` / 추가: 2026-10-22

## 무엇을 하나

문서 본문에 `[[이름]]`을 쓰면 파란 글씨 링크가 된다. 작품 페이지에서 이 링크를 누르면 다음처럼 동작한다.

| 이름이 가리키는 것 | 동작 |
|---|---|
| 같은 작품의 캐릭터 | 그 캐릭터를 선택한다(오른쪽 정보 상자와 상세 정보가 바뀜). 카드가 화면 가운데 오도록 스크롤한다 |
| 다른 작품의 제목 | 그 작품 페이지로 이동한다(같은 창) |
| 둘 다 아님 | "찾을 수 없습니다" 안내창을 띄운다 |

적용 위치는 작품 페이지의 개요, 설정, 하위 문서 본문, 캐릭터 상세 본문이다.

## 규칙

- 이름 비교는 공백과 대소문자를 무시하는 완전 일치다. "레온 폰 아인하르트"와 "레온폰아인하르트"는 같은 이름이지만 "레온"만으로는 찾지 못한다(부분 일치 없음).
- 같은 작품 캐릭터가 먼저 검색되고, 없을 때만 작품 제목을 서버에서 조회한다.
- 숨김 처리된 캐릭터는 카드가 없으므로 찾지 않는다.
- 폼 스왑(이중인격) 중인 캐릭터는 본체 이름과 지금 보이는 서브폼 이름 모두로 찾고, 지금 보이는 쪽을 선택한다.
- 지금 보고 있는 작품 자신의 제목은 작품 이동 대상에서 뺀다.
- 편집기 미리보기의 링크는 이번 변경 대상이 아니다(기존 동작 그대로).

## 용어

- **백링크(backlink)**: 본문 속 이름으로 다른 문서나 캐릭터로 이어 주는 링크. 이 프로젝트에서는 `[[이름]]` 문법이다.
- **폼 스왑**: 이중인격처럼 한 캐릭터가 서브폼으로 바뀌어 보이는 기능(정보 상자 사진을 Shift+클릭).
- **카드**: 작품 페이지의 캐릭터 목록 칸. 각 카드는 `char-card-번호` 식별자를 가진다.

## 구조

- `backlink.js`: 이름 정규화, 같은 작품 캐릭터 찾기, 다른 작품 찾기(순수 함수).
- `useWorkBacklink.js`: 클릭 처리 훅. 캐릭터면 선택과 스크롤, 작품이면 이동, 아니면 안내.
- `MarkdownRenderer.jsx`: 파란 링크 클릭 시 글자를 `onNodeClick`으로 넘긴다.

## 검증

`npm test`: 이름 비교와 대상 찾기(숨김, 폼 스왑, 부분 일치 제외), 훅의 세 갈래 동작과 조회 실패, 작품 페이지 4곳에 연결됐는지. 연결을 되돌리면 3개가 실패하는 것을 확인했다. 실제 앱에서 링크를 눌러 보는 확인은 하지 못했다(백엔드를 띄우지 않음).
