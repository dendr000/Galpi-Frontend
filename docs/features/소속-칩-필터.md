# 소속과 등급 칩 필터

> 대상 파일: `src/domains/character/characterFilter.js`, `FilterChips.jsx`, `CharacterGrid.jsx`, `src/pages/WorkDetail/WorkDetailPage.jsx` / 추가: 2026-10-22 / 계획서: `docs/plans/02-badges-classified-filter-export.md`

## 무엇을 하나

캐릭터 목록 위에 `소속`과 `등급` 속성 값을 칩으로 보여 주고, 눌러서 해당하는 인물만 걸러 본다. 분류 기준을 바꾸지 않고도 "북부 소속만" 같은 보기를 바로 만들 수 있다.

## 사용법

- 칩(`북부 3`: 값과 인원 수)을 누르면 켜지고(굵은 파란 테두리), 다시 누르면 꺼진다.
- 같은 줄(예: 소속) 안에서 여러 칩을 켜면 **하나라도** 맞는 인물이 남는다(OR).
- 다른 줄(소속과 등급)에서 켠 칩은 **모두** 맞아야 남는다(AND). 예: 소속 북부 + 등급 S급이면 둘 다 해당하는 인물만.
- 켠 칩이 있으면 "N / M명"과 "필터 해제" 버튼이 나온다. 맞는 인물이 없으면 "조건에 맞는 인물이 없습니다."가 나온다.

## 규칙

- 칩은 화면에 보이는 캐릭터(숨김 캐릭터 제외, 폼 스왑 반영) 기준으로 만든다. 값이 하나도 없는 줄은 나오지 않는다.
- 값은 쉼표로 나눈다(`북부, 사교`는 칩 두 개). `*`로 시작하는 값은 칩으로 만들지 않고 필터에도 맞지 않는다.
- 값 비교는 공백과 대소문자를 무시한 완전 일치다. 대소문자만 다른 값은 한 칩으로 세고 처음 쓴 표기로 보여 준다.
- 선택은 저장하지 않는다(화면을 나가면 사라진다). 속성 정렬, 기밀 가리기와 함께 쓸 수 있다.
- 칩 글자색은 주변 글자색을 따르고, 선택은 테두리와 굵기로 구분한다(장르 테마별 글자색이 달라서).
- 소속 인물 목록(하위 문서 화면)은 필터와 무관하다.

## 용어

- **칩**: 누르면 켜고 꺼지는 알약 모양 버튼.
- **OR / AND**: OR는 여러 조건 중 하나만 맞아도 통과, AND는 모든 조건이 맞아야 통과.

## 구조

- `characterFilter.js`: 칩 그룹 만들기(`collectFilterGroups`), 걸러내기(`filterChars`), 칩 켜고 끄기(`toggleFilterValue`).
- `FilterChips.jsx`: 칩 그리기. `CharacterGrid.jsx`: 칩과 0명 안내 표시.
- `WorkDetailPage.jsx`: 선택 상태를 들고 그리드에 걸러진 캐릭터를 넘긴다.
