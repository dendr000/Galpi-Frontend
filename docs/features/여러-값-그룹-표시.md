# 여러 값일 때 그룹 표시

> 대상 파일: `src/domains/character/characterGroups.js`, `src/pages/Editor/components/WorkMetaPanel.jsx`, `src/pages/Editor/hooks/useEditorFetch.js`, `useEditorSave.js`, `useEditorState.js`, `src/pages/WorkDetail/WorkDetailPage.jsx`, `src/domains/work/export/prepareExportModel.js` / 추가: 2026-10-27

## 무엇을 하나

작품 페이지의 "분류 기준"(소속, 관계 등)으로 캐릭터를 묶을 때, 값이 여러 개(`북부, 사교`)인 캐릭터를 **어느 그룹에 보일지** 작품마다 고른다.

| 선택 | 동작 (`북부, 사교`인 캐릭터) |
|---|---|
| 모든 값의 그룹에 표시 (기본) | 북부 그룹과 사교 그룹에 모두 카드가 나온다(예전 동작) |
| 첫 번째 값의 그룹에만 표시 | 북부 그룹에만 나온다 |
| 마지막 값의 그룹에만 표시 | 사교 그룹에만 나온다 |

같은 캐릭터 카드가 여러 그룹에 반복되어 자리를 차지하던 문제를 데이터를 바꾸지 않고 푼다. `#소속`처럼 값에 표시를 덧붙일 필요가 없다.

## 어디서 정하나

작품 편집 화면의 "상세 속성 설정" 안 **"여러 값일 때 그룹 표시"** 선택칸. 저장하면 작품 정보(메타)의 `multiGroup` 값으로 들어간다. 기본(모두)이면 값을 저장하지 않고 예전에 저장된 값도 지운다.

## 규칙

- **첫 번째, 마지막은 `*`로 시작하는 값을 뺀 뒤에 센다.** `*비밀, 북부, 사교`의 첫 번째는 `북부`다.
- 값이 하나뿐이거나 비어 있거나 `*`뿐인 캐릭터는 어떤 선택이든 그대로다(비면 "미분류").
- 선택은 작품 전체에 적용되며 **어떤 분류 기준을 골라도 같이 적용된다.** 예를 들어 `관계`가 `친구, 연인`처럼 여러 값이면 그 기준에서도 첫 번째, 마지막 값만 쓴다.
- 공개용 HTML 내보내기도 같은 선택을 따른다.
- 그룹 묶기에만 영향을 준다. 아래는 그대로 모든 소속을 본다.
  - 하위 문서의 "소속 인물" 목록(같은 소속이면 모두 나온다)
  - 칩 필터의 `소속` 칩
  - 정보 상자와 카드에 보이는 `소속` 값 자체
- 잘못된 값이나 없는 값은 "모두"로 본다.

## 용어

- **분류 기준**: 작품 페이지 캐릭터 목록 위에서 고르는 "분류 기준:" 선택(소속, 관계 등).
- **메타(META_DATA)**: 작품 설명 맨 앞에 JSON으로 저장되는 작품 설정 묶음. 개요, 확장자, 등급 설정 등이 여기 들어간다.

## 검증

`npm test`: 그룹 계산(모두, 첫 번째, 마지막, `*` 값 제외, 값이 하나뿐이거나 없을 때, 알 수 없는 값), 메타 읽기와 저장 보조 함수, 편집기 불러오기와 저장(바꾸면 저장, 모두로 되돌리면 삭제), 편집기 선택칸, 작품 페이지와 공개용 내보내기 연결. 연결과 계산을 하나씩 되돌리는 변이 검사 5가지가 모두 테스트 2개씩 실패하는 것을 확인했다. 백엔드를 띄우지 않아 실제 편집 화면은 눈으로 보지 못했다.
