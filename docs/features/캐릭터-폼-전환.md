# 캐릭터 폼 전환 (진화 체인)

한 캐릭터 카드에서 SHIFT+좌클릭으로 다른 모습(진화체, 이중인격)을 차례로 보여 주는 기능입니다.

## 쓰는 법

1. 모든 폼을 캐릭터로 만든다. (예: 헬퍼피, 헬독, 헬가드)
2. 각 캐릭터 편집 화면의 "스위칭" 칸에 **바로 다음 폼**을 고른다.
   - 헬퍼피 -> 헬독, 헬독 -> 헬가드, 헬가드는 비워 둔다.
3. 갤러리에는 처음 모습만 보이게, 나머지 폼은 "목록에서 숨기기"를 켠다.
4. 갤러리에서 카드를 SHIFT+좌클릭하면 헬퍼피 -> 헬독 -> 헬가드 순서로 바뀌고, 헬가드에서 한 번 더 누르면 헬퍼피로 돌아온다.

## 용어

- **스위칭 대상**: 이 폼에서 SHIFT+클릭했을 때 다음에 보일 캐릭터. 마지막 폼은 비워 두면 처음으로 돌아간다.
- **본체 자리**: 갤러리 카드가 놓인 자리. 첫 번째 폼(헬퍼피)이 차지하며, 폼이 바뀌어도 이 자리는 그대로다.
- 현재 보이는 폼은 브라우저에 저장되어(작품별) 다시 열어도 유지된다.

## 동작 규칙 (resolveFormSwitch)

- 스위칭 대상이 있으면 그 캐릭터로 바꾼다. 대상이 본체 자리면 원래 상태로 되돌린다.
- 대상이 없고 지금 본체가 아닌 폼이면 본체로 복귀한다.
- 둘 다 아니면 이미지 바리에이션 순환을 한다.

## 화면에서 설정하기

### 일괄 관리 스튜디오 (표에서 한꺼번에)

- 이름 오른쪽에 **목록 표시**(보임/숨김 버튼)와 **다음 폼 (SHIFT+클릭)**(캐릭터 고르는 목록) 칸이 있다.
- 숨김인 행은 글자가 흐리고 왼쪽에 어두운 띠가 붙어 한눈에 구분된다.
- 위쪽 "폼 전환 설정" 줄: 숨김 수와 연결 수 요약, 체크한 행에 적용하는 **선택 숨기기 / 선택 보이기 / 진화 체인으로 연결 / 연결 해제**.
- **진화 체인으로 연결**: 체크한 캐릭터를 표 순서대로 이어 준다. 첫 캐릭터만 보이고 나머지는 숨기며, 각 캐릭터의 다음 폼은 바로 다음 행이고 마지막은 비운다. 2명 이상 체크해야 눌린다.
- 이름을 바꾸면 그 이름을 다음 폼으로 가리키던 캐릭터의 연결도 같이 바뀐다.
- "전체 데이터베이스에 일괄 저장"을 눌러야 서버에 반영된다.

### 작품 페이지 (숨김 되돌리기)

- 숨김 캐릭터가 있으면 등장인물 목록 위에 **숨김 캐릭터 N명** 띠가 나온다.
- 눌러서 펼치면 이름과 "어느 캐릭터의 폼인지"가 보이고, **복구**(하나씩) 또는 **모두 복구**로 바로 목록에 되돌린다. 바로 서버에 저장된다.
- 진화체를 복구하면 갤러리에 따로 나타난다. 다시 폼으로 묶으려면 스튜디오에서 숨김과 연결을 설정한다.
