# 소속 문서 연결

> 대상 파일: `src/domains/work/organization.js`, `src/domains/character/AffiliationLinks.jsx`, `PageMemberList.jsx`, `src/domains/work/useSelectCharFromUrl.js` / 추가: 2026-10-22 / 계획서: `docs/plans/01-affiliation-page-and-sort.md`

## 무엇을 하나

캐릭터의 `소속` 값과 **같은 제목의 하위 문서**가 있으면 둘을 이어 준다.

| 위치 | 동작 |
|---|---|
| 정보 상자와 카드의 `소속` 값 | 같은 제목의 하위 문서가 있으면 점선 밑줄 링크가 되어 그 문서로 이동한다 |
| 그 하위 문서 화면 | 본문 아래에 "소속 인물 (N)" 카드 목록이 자동으로 나온다 |
| 인물 카드 | 누르면 작품 페이지(`?charId=번호`)가 열리고 그 캐릭터가 선택되어 카드로 스크롤된다 |

새 데이터 구조는 없다. 작품에 "R.S.A.C." 같은 제목의 하위 문서를 만들고 본문에 소개와 직급표를 쓰면 된다.

## 규칙

- 소속은 쉼표로 여러 개를 쓸 수 있고, 값마다 따로 연결한다(`북부, 사교`).
- 이름 비교는 공백과 대소문자를 무시한 완전 일치다. 같은 제목의 문서가 여럿이면 먼저 나온 것으로 연결한다.
- `*`로 시작하는 소속은 링크도 인물 목록도 만들지 않는다(그룹 분류와 같은 규칙). 화면에는 `*`를 뗀 글자로 보인다.
- 숨김 캐릭터는 인물 목록에서 뺀다.
- 인물 목록은 캐릭터 목록의 정렬 선택(속성값 정렬)을 따른다. 정렬을 고르지 않았으면 원래 순서다.
- 링크 글자색은 주변 글자색을 그대로 쓰고 점선 밑줄로만 링크임을 알린다(장르 테마별 글자색이 달라서).
- 카드 안의 링크를 눌러도 카드 선택은 바뀌지 않는다.

## 용어

- **하위 문서**: 작품 아래에 붙이는 위키 문서(`/work/번호?pageId=문서번호`).
- **`?charId=`**: 주소에 붙는 캐릭터 번호. 이 주소로 작품 페이지를 열면 그 캐릭터가 자동 선택된다.
- **소속 인물 목록**: 하위 문서 제목과 같은 소속을 가진 캐릭터를 모은 카드 목록.

## 구조

- `organization.js`: 소속 값 쪼개기, 같은 제목 문서 찾기, 소속 인물 모으기(순수 함수).
- `AffiliationLinks.jsx`: 소속 값을 링크 포함 형태로 그린다(정보 상자, 카드에서 공통 사용).
- `PageMemberList.jsx`: 하위 문서 아래 인물 카드 목록.
- `useSelectCharFromUrl.js`: `?charId=`로 열리면 선택과 스크롤을 한 번 처리한다. 주소에서 `charId`가 없어졌다가 다시 오면 다시 처리한다.

## 검증

`npm test`: 소속 값 쪼개기, 문서 찾기, 인물 모으기(경계: `*`, 숨김, 공백), 링크 클릭 시 이동과 카드 선택 유지, 인물 카드 이동 주소, 주소 선택 훅, 작품 페이지 연결. 연결 코드를 되돌리면 17개가 실패하는 것을 확인했다. 실제 앱 화면은 백엔드를 띄우지 않아 보지 못했다.
