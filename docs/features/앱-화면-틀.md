# 앱 화면 틀 (전체 폭)

> 대상 파일: `src/utils/layoutWidth.js`, `src/store/useSettingStore.js`, `src/App.jsx`, `src/pages/WorkDetail/WorkDetailPage.jsx`, `src/styles/global.css`, `src/components/common/SettingModal.jsx`, `src/domains/work/panelLayout.js`, `src/domains/work/FloatingLeftTree.jsx`, `FloatingToc.jsx`, `src/hooks/useWindowWidth.js` / 추가: 2026-11-09 / 계획서: `docs/plans/05-app-shell.md` (M1 전체 폭, M2 고정 패널까지 구현, 상단 메뉴 바는 다음 단계)

## 무엇을 하나

갈피를 "가운데 좁은 웹 페이지"가 아니라 **창을 가득 채우는 앱**처럼 보이게 한다. 작품 페이지(M1)에 이어 홈, 분류(M4)도 같은 규칙을 따른다.

- 작품 페이지의 장르 테마 영역(배경, 장식)이 창 전체 폭으로 펼쳐져, 양옆 빈 곳까지 테마 배경이 이어진다.
- 본문은 읽기 좋은 폭(본문 960px + 간격 30px + 정보 상자 340px, 모두 합쳐 약 1330px)으로 가운데에 모인다. 창을 아무리 넓혀도 글줄이 한없이 길어지지 않는다.
- 홈과 분류 페이지도 창 폭을 채운다. 분류 카드는 폭에 맞춰 한 줄에 놓이는 개수가 늘고 줄며(카드 최소 190px), 반쪽 창에서도 가로 스크롤이 생기지 않는다.
- 편집기, 일괄 편집, 메모 화면은 예전부터 창 전체를 쓰고, 이제 맨 위에 메뉴 바가 붙는다(`docs/features/상단-메뉴-바.md`). 이 세 화면의 높이는 화면 높이에서 메뉴 바 28px(와 편집기, 메모의 자체 머리글 60px)를 뺀 값이다.
- 설정에서 "본문 폭 제한(1200px)"을 고르면 예전처럼 1200px 가운데 칸으로 돌아간다.

## 설정하는 곳

환경 설정 > 레이아웃.

| 선택 | 동작 |
|---|---|
| 전체 폭 (창을 가득 채움) — 기본 | 앱이 창 전체를 쓰고, 작품 페이지 테마 영역도 전체 폭 |
| 본문 폭 제한 (1200px, 가운데 정렬) | 앱 전체가 1200px 가운데 칸(예전 기본) |

편집기, 일괄 편집, 메모 화면은 어느 쪽이든 원래 창 전체 폭이다.

## 양옆 패널 (문서 트리, 목차)

작품 페이지의 왼쪽 **문서 트리**와 오른쪽 **목차**는 예전에는 마우스를 화면 가장자리에 대야 나타나는 숨은 패널이었다. 이제 창이 넓으면(**1650px 이상**) 본문 옆에 붙은 고정 열로 항상 보인다.

| 창 폭 | 동작 |
|---|---|
| 1650px 이상 | 왼쪽 트리(260px)와 오른쪽 목차(260px)가 본문 양옆에 붙어 있다. 위아래로 스크롤해도 패널은 화면에 머물고, 내용이 길면 패널 안에서만 스크롤한다 |
| 1650px 미만 (반쪽 창 등) | 예전처럼 화면 가장자리의 손잡이로 접힌다. 마우스를 대면 펼쳐진다 |

- 붙은 패널 위쪽의 **접기 버튼**(화살표)을 누르면 그 패널만 접혀 손잡이로 바뀐다. 접힌 손잡이를 **누르면** 다시 붙는다(넓은 창에서만).
- 접어 둔 선택은 환경 설정 저장소(`panelLeftOpen`, `panelRightOpen`)에 저장돼 다음에 열어도 유지된다. 창이 좁아서 접힌 것은 저장하지 않으므로, 창을 다시 넓히면 원래 선택대로 돌아온다.
- **정보 상자(캐릭터 인포박스)는 패널로 옮기지 않았다.** 장르 테마의 색과 장식은 테마 영역(`#galpi-genre-zone`) 안에서만 적용되는데, 패널은 그 바깥에 있어서 옮기면 정보 상자의 테마가 사라진다. 그래서 본문 옆 자리에 그대로 둔다.
- 붙는 기준 폭은 `src/domains/work/panelLayout.js` 의 `DOCK_MIN_WIDTH` 한 곳에서 바꾼다. 두 패널과 본문 옆 정보 상자를 빼고도 본문이 약 730px 남는 폭으로 잡았다.
- 구조: `FloatingLeftTree`, `FloatingToc` 는 `docked` 속성으로 붙은 열과 접힌 손잡이를 모두 그린다. 작품 페이지가 `.galpi-work-shell`(가로 배치) 안에 "왼쪽 패널, 테마 영역, 오른쪽 패널" 순으로 놓는다. 패널 높이는 위아래 고정 영역(`--app-header-h`, `--app-footer-h`)을 뺀 만큼이다.

## 옛 설정은 어떻게 되나

예전 기본값은 "가운데 정렬"이었다. 이 버전을 처음 열 때 **옛 설정이 "가운데 정렬"로 저장돼 있었다면 한 번만 "전체 폭"으로 바뀐다.** 그 뒤에 직접 "본문 폭 제한"을 고르면 그 선택이 그대로 유지된다(다시 바뀌지 않는다). 설정 저장 형식에 버전을 달아(`galpi-settings` 의 `version`) 이 "한 번만"을 구분한다.

## 구조(개발자용)

- `getAppMaxWidth` — 앱 최상위 칸(`.galpi-app`)의 최대 폭. 편집기, 일괄, 메모 모드는 항상 100%.
- `getWorkZoneLayout` — 작품 페이지 영역 클래스. 전체 폭이면 `#galpi-genre-zone` 에 `galpi-work-full`, 그 안쪽 칼럼에 `galpi-work-inner`(읽기 폭)를 쓰고, 제한이면 예전 `fixed-container` 를 쓴다.
- `getPageContainerClass` — 홈, 분류 같은 일반 화면 칸의 클래스. 전체 폭이면 `fixed-container galpi-page-fluid`(`global.css` 에서 1200px 제한을 풂), 제한이면 `fixed-container`.
- `appChrome.js` 의 `getChromeVisibility` — 화면(주소)별로 메뉴 바, 상단 바, 떠 있는 메뉴, 푸터를 보일지 정한다. 메뉴 바는 모든 화면, 상단 바는 편집기, 일괄, 메모만 숨김, 떠 있는 메뉴와 푸터는 일괄만 숨김. `App.jsx` 가 이 값을 쓴다.
- `--app-menubar-h`(28px) — 상단 바가 없는 화면의 높이 계산에 쓰는 CSS 변수(`global.css`).
- `migrateSettings` — 저장된 설정을 새 버전으로 옮긴다(`useSettingStore` 의 persist `migrate`).
- 장르 테마 CSS 는 영역에 6px 둥근 모서리를 주는데, 창 가장자리까지 닿는 전체 폭에서는 `global.css` 에서 각지게 덮어쓴다. 장식(번짐, 점 무늬)이 영역 밖으로 새지 않도록 `clip-path` 는 유지한다.

## 용어

- **장르 테마 영역**: 작품 분류(무협, 사이버펑크 등)에 맞춰 배경과 글꼴을 바꾸는 작품 페이지의 큰 상자(`#galpi-genre-zone`).
- **읽기 폭**: 글줄이 너무 길지 않게 본문을 가두는 폭. 한 줄이 길면 눈이 다음 줄을 찾기 힘들다.
- **마이그레이션**: 앱 업데이트로 설정의 기본값이 바뀔 때, 이미 저장된 옛 설정을 새 형식으로 한 번 옮기는 작업.

## 아직 안 한 것(다음 단계)

- 목차에서 현재 보고 있는 제목 강조(3단계, 긴 문서 보기와 함께)
- 홈과 분류의 실제 화면 확인(백엔드가 필요해 사용자가 직접). 분류 페이지는 이전에 최대 1600px 였으나 이제 창 폭을 모두 쓴다.

## 확인한 것

- 정적 CSS 시험 화면(실제 `global.css` 와 테마 CSS 사용)으로 1920px 에서 영역이 창 전체, 안쪽 칼럼 1330px(본문 960, 정보 상자 340)로 가운데, 가로 스크롤 없음, 테마 배경과 장식이 가장자리까지 이어짐을 확인했다. 테마 없는 작품과 "본문 폭 제한"도 확인했다.
- 양옆 패널은 같은 방식의 시험 화면(실제 CSS 사용)에서 1920px 일 때 패널이 창 양끝에 붙고, 높이가 화면 높이에서 위아래 고정 영역(61px, 48px)을 뺀 값(1000px 화면에서 891px)이며, 스크롤해도 패널이 화면에 머물고 가로 스크롤이 없음을 확인했다(정보 상자를 옮기던 첫 설계 때 시험, 이후 정보 상자를 본문 옆에 두도록 바꾸고 오른쪽 패널을 260px 로 줄였다).
- 실제 작품 페이지(백엔드와 로그인 필요)는 사용자가 직접 확인해야 한다.
- 분류 화면의 실제 CSS 와 메뉴 바를 시험 화면에 올려 확인: 1920px 라이트에서 카드 9열, 창 폭 전체 사용. 960px(반쪽 창) 다크에서 4열, 가로 스크롤 없음. 본문 폭 제한을 켜면 1200px 로 줄고 5열. 모든 경우에 메뉴 바 높이 28px.
