# 콘솔 로그 켜고 끄기

> 대상 파일: `src/utils/consoleGate.js`, `src/utils/installConsoleGate.js`, `src/main.jsx` / 추가: 2026-11-09

## 무엇을 하나

화면 곳곳에 있는 `console.log` 약 114줄(41개 파일)을 지우지 않고, 필요할 때만 나오게 한다. 웹에서 오류를 확인할 때는 지금처럼 보이고, exe 에서는 기본으로 조용하다.

| 상황 | 기본 |
|---|---|
| 개발 서버(`npm run dev`)로 웹에서 볼 때 | 켜짐(예전과 같음) |
| 배포 빌드(exe, 빌드한 웹) | 꺼짐 |

`console.warn`, `console.error` 는 어느 쪽이든 항상 나온다. 오류를 놓치지 않기 위해서다.

## 직접 켜고 끄기

브라우저 개발자 도구(F12)의 콘솔에서:

```text
galpiDebug(true)    로그 켜기
galpiDebug(false)   로그 끄기
```

고른 값은 이 PC 의 `localStorage`(`galpi.debug`)에 저장되어 다음 실행에도 유지되고, 바로 적용된다. 저장된 값이 있으면 기본값(개발 서버 켬, 배포 끔)보다 우선한다.

## 규칙

- `log`, `debug`, `info` 만 걸러진다. 앱이 시작될 때 가장 먼저 불러오므로(`main.jsx` 첫 줄) 시작 중에 찍는 로그도 걸러진다.
- 여러 번 적용해도 원래 함수를 겹겹이 감싸지 않고, 켜면 원래 함수로 돌아간다.
- 저장소를 못 읽거나(차단된 환경) 못 써도 앱은 멈추지 않고 기본값을 따른다. 못 쓴 경우에도 이번 실행에는 바로 적용된다.

## 용어

- **localStorage**: 브라우저(exe 포함)가 이 PC 에 작은 설정값을 저장해 두는 곳.
- **개발 서버**: `npm run dev` 로 띄우는 개발용 웹 서버. 코드를 바꾸면 바로 화면에 반영된다.

## 검증

`npm test`: 기본값(개발, 배포), 저장된 '1'/'0' 우선, 알 수 없는 값과 저장소 오류, warn/error 유지, 겹겹이 감싸지 않음, 켜고 끄기와 저장, 저장소 접근이 막힌 환경. 계산과 연결을 하나씩 되돌리는 변이 검사 8가지에서 각각 테스트가 실패함을 확인했다.
