# 캐릭터 정보 상자 스크롤

> 대상 파일: `src/domains/character/CharacterInfobox.jsx`, `src/pages/WorkDetail/WorkDetail.module.css` / 수정: 2026-10-22

## 무엇을 하나

작품 페이지 오른쪽의 캐릭터 정보 상자(이름, 이미지, 속성 표, 설명, 수정/삭제 버튼)는 페이지를 내려도 화면 위쪽에 붙어 따라다닌다. 속성이 많아 상자가 화면보다 길어지면 **속성 표와 설명만 스크롤**되고, **이름란과 사진은 위에, 수정/삭제 버튼은 맨 아래에 항상 보인다**(2026-10-22 변경: 처음에는 이름란과 사진도 함께 스크롤됐다).

## 규칙

- 상자 최대 높이는 `화면 높이 - 150px`이다(위쪽 헤더와 아래쪽 고정 푸터 몫).
- 속성 표와 설명만 스크롤 영역(`infoboxScroll`) 안에 있다. 짧으면 스크롤바가 생기지 않는다.
- 이름란과 사진은 스크롤 영역 위에서 줄어들지 않는다. 사진 높이는 `min(300px, 38vh)`라서 낮은 화면에서는 줄어든다(560px 높이 화면에서 약 213px).
- 수정/삭제 버튼 줄(`btn-container`)은 스크롤 영역 밖에 있고 줄어들지 않는다.

## 용어

- **sticky(스티키)**: 스크롤하면 화면의 정해진 위치에 달라붙어 따라오는 배치 방식.
- **스크롤 영역**: 내용이 넘칠 때 그 영역 안에서만 위아래로 움직이는 칸.
- **flex(플렉스)**: 칸 안의 요소를 가로나 세로로 나열하고 남는 공간을 나누는 배치 방식. 여기서는 세로로 쌓고 스크롤 영역이 남는 높이를 쓰게 한다.

## 검증

`npm test`: 속성 표가 스크롤 영역 안에, 수정/삭제 버튼이 밖에 있는지, CSS 에 최대 높이·세로 flex·안쪽 세로 스크롤이 있는지. 수정을 되돌리면 이름란/사진 고정 시험 2개가 실패하는 것을 확인했다. 실제 브라우저 엔진에서 같은 CSS를 쓴 시험용 상자로 확인했다(화면 982px: 상자 832px, 스크롤해도 이름란과 사진 위치 불변, 버튼 화면 안 / 화면 560px: 사진 213px로 축소, 버튼 화면 안). 실제 앱 화면은 백엔드를 띄우지 않아 보지 못했다.
