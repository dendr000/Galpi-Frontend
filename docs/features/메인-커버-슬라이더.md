# 메인 커버 슬라이더

> 대상 파일: `src/pages/Home/HeroSlider.jsx`, `hooks/useHeroSlider.js`, `heroSlides.js` / 개선: 2026-10-13

## 무엇을 하나

메인 화면 맨 위의 큰 커버 이미지 배너다. 작품 커버를 무작위 순서로 늘어놓고 **5초마다 한 장씩 오른쪽으로** 넘긴다. 마지막 그림 다음에도 되감지 않고 계속 오른쪽으로 이어진다. 그림을 누르면 그 작품 페이지로 이동한다.

## 어떤 규칙으로 이미지를 불러오나

1. **대상 작품**: 메인 화면 목록과 같은 작품(숨김 분류에 걸린 작품은 제외) 중에서, 작품 설명 맨 위 메타 정보에 `coverExt`(확장자) 또는 `cover`(옛 방식 경로)가 있는 것만 쓴다. 커버를 지정하지 않은 작품은 나오지 않는다.
2. **순서**: 페이지를 열 때 한 번 무작위로 섞는다(Fisher-Yates). 열려 있는 동안은 순서가 고정되고, 새로고침하면 다시 섞인다.
3. **이미지 주소**:
   - `coverExt`가 있으면 `/img/cover/<작품명>.<확장자>`. 작품명에 파일명으로 못 쓰는 문자(`? : * " < > | \ /`)가 있으면 전각 문자로 바꿔서 찾는다(예: `?` -> `？`).
   - `coverExt`가 없고 `cover`가 있으면 옛 방식 경로(`cover/파일명`에서 `cover/`를 뺀 이름)를 쓴다.
   - 이미지 파일은 `Galpi-Media/img/cover/` 폴더에 있고 백엔드가 `/img/cover/...`로 내보낸다.
4. **표시 방식**: 메타의 `coverX`, `coverY`(기본 50%)는 그림 위치, `coverZ`(기본 `cover`)는 확대 정도다.
5. **로딩**: 슬라이드마다 배경 이미지로 지정돼 있어서, 대상 작품의 커버를 페이지를 열 때 한꺼번에 요청한다.

## 되감기를 없앤 방법

예전에는 마지막 그림에서 첫 그림으로 돌아갈 때 전체 트랙이 왼쪽으로 쭉 되돌아갔다. 지금은 **트랙 끝에 첫 그림의 복제본을 하나 더 붙인다**.

1. 마지막 그림에서 한 칸 더 오른쪽으로 넘기면 복제본(첫 그림과 똑같은 화면)이 보인다.
2. 그 전환(0.6초)이 끝나면 **전환 효과를 끈 채** 진짜 첫 그림 위치로 순간 이동한다. 화면이 같아서 눈에는 보이지 않는다.
3. 곧바로 전환 효과를 다시 켜서 다음 그림부터 부드럽게 넘어간다.

## 용어

- **트랙**: 슬라이드들을 가로로 이어 붙인 긴 띠. 이 띠를 좌우로 밀어서 한 장씩 보여 준다.
- **복제본**: 첫 그림과 똑같이 하나 더 만든 슬라이드. 끝없이 이어지는 것처럼 보이게 하는 장치다.
- **Fisher-Yates 셔플**: 모든 순서가 같은 확률로 나오는 표준 섞기 방법.
