# 등급 배지와 기준표

> 대상 파일: `src/domains/character/ratings.js`, `RatingBadges.jsx`, `RatingScaleTable.jsx`, 작품 편집기(`WorkMetaPanel.jsx`) / 추가: 2026-10-22 / 계획서: `docs/plans/02-badges-classified-filter-export.md`

## 무엇을 하나

작품마다 "무엇을 몇 등급으로 매길지"(예: 위험도 R, 유용성 U, 희귀도 S)와 등급 기준표(0 무해 ~ 5 재앙)를 정해 두면, 캐릭터 카드와 정보 상자에 `R 3` 같은 작은 배지가 붙고 작품 페이지에 기준표가 나온다.

## 사용법

1. 작품 편집 화면의 작품 정보(접힘 영역)에서 두 칸을 채운다.
   - **등급 판정 축**: 한 줄에 `속성이름:약칭`. 예: `위험도:R` (약칭을 생략하면 이름 첫 글자)
   - **등급 기준표**: 한 줄에 `등급:명칭:기준`. 예: `3:중대:도시·기관 단위 영향`
2. 캐릭터 편집(또는 일괄 편집)에서 같은 이름의 속성(예: `위험도`)에 `3` 같은 값을 넣는다.
3. 작품 페이지에서 카드 이름 아래와 정보 상자 위쪽에 배지가 보인다. 마우스를 올리면 `위험도 3 중대: 도시·기관 단위 영향`이 뜬다.

## 규칙

- 값에서 **처음 나오는 숫자**를 등급으로 읽는다(`3`, `3급`, `등급 3` 모두 3). 숫자가 없거나 값이 비어 있으면 그 배지는 없다.
- 기준표에 없는 등급이면 배지에는 숫자만 보이고 툴팁에 명칭과 기준이 없다.
- 배지의 색은 등급을 나타내는 작은 점에만 쓴다(낮음 회색, 높음 진홍). 글자색은 주변을 따라 어두운 장르 테마에서도 읽힌다.
- 기준표는 작품 첫 화면의 설정 아래에 나온다. 하위 문서 화면에는 나오지 않는다.
- 두 칸을 모두 비우면 배지와 기준표가 사라진다(저장된 옛 값도 지워진다).
- 설정은 작품 설명의 메타(`ratingAxes`, `ratingScale`)에 문자열로 저장된다. 서버 변경은 없다.

## 용어

- **판정 축**: 등급을 매기는 기준 항목(위험도, 유용성 등). 캐릭터 속성 이름과 같아야 한다.
- **약칭**: 배지에 쓰는 한 글자 표기(R, U 등).
- **기준표**: 각 등급이 무엇을 뜻하는지 적은 표.
- **배지(칩)**: 이름 아래에 붙는 작은 알약 모양 표시.

## 구조

- `ratings.js`: 두 문자열 해석, 캐릭터별 배지 계산, 점 색, 저장 시 메타 반영(순수 함수).
- `RatingBadges.jsx`: 배지 그리기. `RatingScaleTable.jsx`: 기준표 그리기.
- `CharacterGrid.jsx`, `CharacterInfobox.jsx`: 배지 표시. `WorkDetailPage.jsx`: 설정을 읽어 연결.
- `useEditorFetch.js`, `useEditorSave.js`, `useEditorState.js`: 편집기에서 불러오기와 저장.
