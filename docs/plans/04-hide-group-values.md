## 1. 요청과 배경

| 요청(원문) | 결정 |
|---|---|
| "문서 속성 및 개요 설정에서 임의로 어느 속성값은 캐릭터 그리드에 안 보이게 설정할 수 있을지? 소속이 너무 세분화되면 소속이 여러 개인 캐릭터는 여러 번 보여가지고." | 작품 설정에 "그룹에서 숨길 값" 칸을 추가한다. 적은 값은 캐릭터 그리드의 그룹(소속별, 등급별 등)에서 빠지고, 그 값을 가진 캐릭터는 남은 값의 그룹에만 보인다. |

한 줄 정의: 작품 설정에서 속성별로 "이 값은 그룹으로 만들지 않는다"를 지정해, 값이 여러 개인 캐릭터가 불필요한 그룹에 중복으로 나오지 않게 한다.

## 2. 목표와 비목표

- 목표
  - 작품 문서의 "상세 속성 설정"에 `속성명: 값1, 값2` 형식(그룹 정렬 순서와 같은 형식)으로 숨길 값을 적는다.
  - 작품 페이지 그리드, 카드 끌기(순서 바꾸기), 내보내기가 같은 기준으로 숨긴다.
  - 분류 기준(관계, 소속, 등급 등)마다 따로 지정할 수 있다.
- 비목표(지금 하지 않음)
  - 캐릭터 카드를 그리드에서 통째로 숨기는 것. 캐릭터 문서의 "숨김" 설정이 따로 있다.
  - 그룹 머리글을 눌러 숨기는 화면 조작(설정 칸만 둔다). 필요해지면 다음에 다룬다.
  - 하위 문서(소속 문서) 페이지의 구성원 목록 변경.

## 3. 현재 상태·조사

- 그룹 묶기는 `characterGroups.js` 의 `getGroupTags` 가 한다. 쉼표로 여러 값이면 `multiGroup`(모두, 첫 값, 마지막 값) 설정에 따르고, `*` 로 시작하는 값은 캐릭터 쪽에서 처음부터 뺀다. 값이 모두 빠지면 "미분류"가 된다.
- 같은 함수를 화면(`buildCharacterGroups`), 카드 끌기(`useCharacterDrag`), 내보내기(`prepareExportModel`)가 쓴다.
- 작품 설정은 작품 설명 맨 앞 `[META_DATA:{...}]` 에 저장된다. 그룹 정렬 순서는 `_groupOrder: {속성명: [값...]}` 이고, 편집기(`useEditorFetch`, `useEditorSave`)가 문자열(`groupOrderStr`)과 변환한다.
- 이미 있는 "여러 값일 때 그룹 표시"는 전체 규칙(첫 값, 마지막 값)이라 "특정 값만 빼기"는 할 수 없다. `*` 접두사는 캐릭터마다 일일이 써야 한다.

## 4. 설계와 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| 메타 키 `_groupHide: {속성명: [값...]}`, 편집기 문자열은 `속성명: 값1, 값2` 한 줄에 하나 | `_groupOrder` 와 같은 모양이라 배우기 쉽고 저장, 불러오기 코드를 닮게 쓴다 | 캐릭터마다 `*` 쓰기(번거로움), 화면에서 머리글 눌러 숨기기(저장 위치 별도 필요) |
| 숨김은 첫 값, 마지막 값 선택보다 먼저 적용 | "첫 번째"가 숨긴 값이 아니라 보이는 값 중 첫 번째여야 한다. `*` 규칙과 같은 순서 | 선택 뒤 적용(숨긴 값이 첫 값이면 그룹이 비어 버림) |
| 값이 모두 숨겨진 캐릭터는 "미분류"로 간다 | `*` 로만 된 값과 같은 규칙이고, 그리드에서 아예 사라져 접근 못 하는 캐릭터가 생기지 않는다 | 캐릭터를 그리드에서 제외(찾기 어려움) |
| "미분류"는 숨길 수 없다(적어도 무시) | 위 규칙의 연장. 값이 없는 캐릭터가 사라지지 않게 한다 | 미분류 숨김 허용 |
| 값 비교는 앞뒤 공백만 다듬고 대소문자를 구분 | 그룹 이름과 정렬 순서가 이미 그렇게 비교된다 | 대소문자 무시(그룹 이름과 어긋남) |
| 설정을 모두 지우면 메타에서 `_groupHide` 를 지운다 | 지웠는데 옛 값이 살아남으면 안 된다(그룹 정렬 순서는 이 문제가 있어 따라 하지 않는다) | 비어 있어도 그대로 둠 |

## 6. 검증 방침

- 테스트 먼저: 변환 함수, 그룹 묶기(숨김, 첫 값과의 순서, 모두 숨김, 미분류), 편집기 저장과 불러오기와 입력 칸, 내보내기, 작품 페이지.
- 변이 검사: 숨김 적용 순서, 미분류 보호, 지우기 처리.
- 화면은 백엔드가 있어야 뜨므로 실제 모양은 사용자 확인이 필요하다.

## 7. 위험과 대응

| 위험 | 대응 |
|---|---|
| 숨긴 값 때문에 기존 그룹 정렬 순서 설정과 어긋남 | 정렬 순서에 있어도 그룹이 안 만들어질 뿐 오류는 없다(그룹 이름 목록은 실제 그룹에서 만든다) |
| 내보내기와 화면이 다르게 숨김 | 같은 함수(`getGroupTags`)와 같은 입력(메타)을 쓰고 내보내기 테스트를 둔다 |
